# ToDo List

A browser-based ToDo List application developed as a frontend project during my internship training at OneStop.ai.

## Features

- Add new tasks
- Add task descriptions
- Assign tasks to responsible persons
- Set an Estimated Time of Arrival (ETA)
- Display tasks in a structured table
- Mark tasks as completed
- Edit existing tasks
- Store task data using browser localStorage
- Responsive interface using Bootstrap

## Technologies Used

- **HTML5** – Structure of the application
- **Bootstrap 5.3.8** – Responsive layout and UI components
- **JavaScript** – Task management and application logic
- **jQuery 3.7.1** – DOM manipulation and event handling
- **Font Awesome** – Icon resources
- **Bootstrap Icons** – Interface icons
- **LocalStorage** – Client-side storage of task data

## How It Works

Users can add a task by entering its description, responsible person's name, and ETA. The task is then displayed in a table.

Tasks can be marked as completed or edited when required. Task information is stored in the browser's localStorage so that the data can be maintained within the browser.
